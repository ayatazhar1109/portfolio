AI Cybersecurity SOC Agent

Python • Flask • HTML • CSS • JavaScript • MITRE ATT&CK • Railway

A full-stack web application that automates threat detection and reduces alert fatigue for Security Operations Center (SOC) analysts. The system uses a 5-stage AI pipeline (Log Analysis → Threat Detection → Threat Intelligence → Risk Assessment → Incident Response) to analyze security logs in real-time. It features a Human-in-the-Loop architecture that requires analyst approval before executing block actions. The dashboard displays live alerts, an incident summary, and the MITRE ATT&CK mapping for each detected threat.

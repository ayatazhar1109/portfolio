PhishGuard Pro — Real-Time Phishing Detection System

Python • SSL • DNS • WHOIS • Published on Zenodo

A Python-based tool that detects fake websites in real time with 95% accuracy. It performs 16 phishing checks including typosquatting, suspicious TLDs, double-domain tricks, URL shorteners, and missing HTTPS. Includes SSL validation, DNS lookup, WHOIS lookup, HTTP header analysis, URL expansion, and batch scanning of 50+ URLs. Achieved 96% accuracy on legitimate sites and 94% on phishing sites across 100 test URLs.
